# Cambio visual solicitado

Solicitud de Alberto, 2026-10-06:
"que se vea mejor el juego, algo diferentes, no se como un personaje y escenario como un mejor parkour"

Dirección de arte aplicada: azoteas flotantes al atardecer, ciudad estilizada,
mensajero con casco y mochila, contraste cian/naranja, plataformas de diferentes
formas y alturas, cristales y portales luminosos. Se generó geometría con Python
y primitivas nativas; no se envió un prompt a un servicio de generación 3D.

Comparación: la versión anterior tenía un robot de cajas y un laboratorio cerrado.
SKYLINE incorpora un personaje de piezas redondeadas con animación rígida, una
ruta abierta con caídas, puntos de control, cronómetro, récord local y pantalla final.
El modelo original y el laboratorio se conservan como escenas independientes.
